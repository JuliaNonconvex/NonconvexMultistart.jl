# NonconvexMultistart

![JuliaNonconvex logo](https://raw.githubusercontent.com/JuliaNonconvex/NonconvexMultistart.jl/master/docs/src/assets/logo.png)



## Description

[Hyperopt.jl](https://github.com/baggepinnen/Hyperopt.jl) is a Julia library that implements a number of hyperparameter optimization algorithms which can be used to optimize the starting point of the optimization. `NonconvexHyperopt.jl` allows the use of the algorithms in `Hyperopt.jl` as meta-algorithms using the `HyperoptAlg` struct.

See [Quick start](quickstart.md) for the first steps, [Options](options.md)
for the algorithm options, [Sampler choice](samplers.md) for the starting
point samplers, [Result](result.md) for the fields of the returned result and
[Docstrings](docstrings.md) for the full API reference.
